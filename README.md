# AMANEKU 体験サイト（MVP・形だけ版）

HTMLとCSSだけの静的サイト。ビルドは不要。予約・決済はまだつないでいない。

## 見方
`index.html` をブラウザで開く（ブラウザの言語で英語版／日本語版に振り分ける）。
直接開くなら `en/index.html` か `ja/index.html`。

## 構成
- `en/` 英語版、`ja/` 日本語版（同じ4ページ）
  - `index.html` トップ
  - `experience.html` 長唄体験
  - `artist.html` 演奏家（インタビュー形式）
  - `booking.html` 予約の流れ・FAQ
- `assets/style.css` 共通のデザイン
- `assets/site.js` 未定メモの表示切り替え
- `assets/img/` 画像
- `docs/` 分析などのメモ

## デザインの考え方
- 主役は音楽（長唄・三味線）。歌舞伎は背景。
- 色は墨・和紙・金・朱。区切りは三味線の三本の糸、帯は定式幕（黒・柿・萌葱）、背景に青海波。
- 「聴く・弾く・合わせる」を大きな漢字で見せる。口三味線「チントンシャン」を飾りに使う。

## 未定の部分
- 普段は、公開しても問題ない仮の文章（「近日公開」など）を表示している。
- 右下の黄色いボタン「未定メモを表示」を押すと、未定の部分が点線で囲まれ、何を書くかのメモが出る。
- 決まったら、英語版と日本語版の両方を書き換える（`class="tbd"` と `data-note` を外す）。
- **公開前に `assets/site.js` の未定メモボタンの部分を消す**（言語の記憶の部分は残す）。

## 予約カレンダー（`assets/booking.js`）
- 予約できる日は明るく、満席の日は打ち消し線、開催なしは灰色。
- 日付を押すと、その日の回が演奏家ごとのカード（写真・時間・場所・料金・残り枠）で並ぶ。カードを押すと詳細が開く。
- 日程・演奏家・会場は **Supabase（`get_available_slots`）から読み込む**。管理画面で足した枠がそのまま出る。今の中身は架空のダミー。
- 公開サイトに置いているのは anon（公開用）の鍵だけ。空き状況しか見られない。
- 予約ボタンはまだ押せない（決済をつなぐのは次の段階）。

## 言語の切り替え
- 日本語設定のブラウザで英語版を開くと、表示前に日本語版へ移る（英語版の各ページの `<head>` 先頭のスクリプト）。
- 右上の言語ボタンを押すと選択を覚えるので、自分で English を選んだ人は英語版のまま。
- 「AMANEKU」は `translate="no"` を付けて、ブラウザの自動翻訳で「アマネク」にならないようにしている。

## 中身の出どころ

## 更新したら（ブラウザの古い保存を避ける）
CSS・JSを変えたら、各ページの `?v=20261021c` を新しい値に置き換える（全ページ一括で）。
GitHub Pages はファイルを10分ほどブラウザに保存させるため、番号を変えないと古い見た目が残ることがある。
